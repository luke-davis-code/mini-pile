A locally run website where a user can track their miniature painting backlog and wishlist. Designed with a mobile first UI.

Built with Laravel, Inertia, Vue (Composition API), TypeScript, Tailwind, [shadcn-vue](https://www.shadcn-vue.com/) component library. Started with Laravel Vue [starter kit](https://laravel.com/framework/docs/13.x/starter-kits#vue).

Currently can be run locally using `composer run dev` then going to http://localhost:8000/.

Can run unit tests using `php artisan test`.

Features (progress):
- [x] Collection Page
- [ ] Painting Lists & Painting Items
- [ ] Miniature Set Catalogue
    - [ ] User add custom entries to catalogue
- [ ] Dashboard
- [ ] Wishlist
